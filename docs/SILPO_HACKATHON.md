# Silpo AI Factory — заявка «Смарт-кошик Сільпо»

Прототип для хакатону [«Сільпо» AI Factory](https://ai-factory.silpo.ua/) —
AI-агент, що з побутового запиту («збери кошик для борщу на 6 осіб до
800 грн») формує реальний кошик покупок через офіційний
**MCP «Сільпо»** (`https://mcp.silpo.ua/mcp`).

## Ключові факти про конкурс

- **Призовий фонд:** 100 000 ₴
- **Реєстрація:** до **31 серпня** на https://ai-factory.silpo.ua/#register
  (після реєстрації видають доступ до документації MCP і Starter Kit)
- **Старт хакатону:** 1 вересня, 09:00
- **Вимоги до проєкту:**
  1. підключення до `https://mcp.silpo.ua/mcp`;
  2. виклик щонайменше одного інструмента з `tools/list` у робочому сценарії;
  3. робочий прототип/демо, яке показує цей виклик;
  4. токени зберігаються на сервері, а не в клієнтському коді.

## Що віддає сервер (39 інструментів)

За документацією, MCP «Сільпо» публікує 39 інструментів у категоріях:

| Категорія | Можливості | Тип |
|---|---|---|
| Локація й доставка | пошук адреси, типи доставки, магазини, тайм-слоти, відділення НП | read/write |
| Пошук товарів | пошук, **пакетний пошук до 30 позицій**, підбір замін | read |
| Каталог | акції, категорії, кураторські добірки | read |
| Кошик | додавання/видалення, оновлення доставки, промокоди, сертифікати | **write** |
| Замовлення | історія онлайн- і офлайн-покупок з чеками | read |
| Профіль | дані гостя, адреси, склад родини, харчові обмеження | read/write |
| Лояльність | балабонуси, купони, промокоди, статус Premium | read/**write** |

Умова участі: рішення має ходити **лише через офіційний MCP**, без
сторонніх/неофіційних API.

## Ідея: «Смарт-кошик Сільпо»

Агент-покупець природною мовою: планування меню → пакетний пошук
інгредієнтів → заміни відсутніх → порівняння акцій → зібраний кошик →
посилання на чекаут (фінальний клік завжди за людиною). Технічно це
демонструє наскрізний ланцюжок *LLM ⇄ MCP «Сільпо»* і легко розширюється
(Telegram-бот уже є в цьому репозиторії).

## Guardrails: хто відповідає за кошик

Сервер дає write-доступ до кошика, доставки й лояльності, але документація
не описує ні лімітів, ні механізму підтвердження. Тому відповідальність
вбудовано на рівні агента — і це свідома фішка заявки:

1. **Класифікація інструментів** (`guardrails.py`): read/write за
   дієсловами назви; невідоме дієслово консервативно вважається write.
2. **Human-in-the-loop**: кожна write-дія (додати в кошик, застосувати
   балабонуси, змінити доставку) вимагає явного підтвердження користувача
   в CLI (`--yes` — автопідтвердження для демо, `--read-only` — повна
   заборона write-дій).
3. **Аудит-лог** (`--audit file.jsonl`): кожен виклик інструмента
   фіксується — хто, що, чи було дозволено. Це і є відповідь на питання
   «хто натиснув кнопку».
4. **Промпт-рівень**: агенту заборонено списувати бонуси/купони без явного
   прохання та оформлювати замовлення — він доводить до чекаут-лінка.

## Архітектура

```
Користувач ──> app/silpo_agent/cli.py (або Telegram)
                      │
                      ▼
              SilpoAgent (Claude, модель claude-opus-5, агентний цикл tool use)
                      │  tools/list + tools/call
                      ▼
              SilpoMCPClient (MCP Streamable HTTP, JSON-RPC 2.0)
                      │  Authorization: Bearer $SILPO_MCP_TOKEN (server-side)
                      ▼
              https://mcp.silpo.ua/mcp
```

- `app/silpo_agent/mcp_client.py` — власний легкий MCP-клієнт на `requests`:
  initialize/initialized, `tools/list` (з пагінацією), `tools/call`,
  підтримка відповідей JSON і SSE, заголовок `Mcp-Session-Id`.
- `app/silpo_agent/agent.py` — агентний цикл на Anthropic SDK: схеми
  інструментів беруться з `tools/list` і передаються Claude, виклики
  виконуються через MCP, результати повертаються моделі до фінальної
  відповіді. Увімкнено server-side fallback (якщо запит відхилять
  класифікатори Claude Opus 5, його автоматично повторить резервна модель).
- `app/silpo_agent/cli.py` — демо: `--list-tools`, `--call`, повний сценарій,
  опційна відправка результату в Telegram.

## Персоналізація: профіль користувача

Локальний профіль (`silpo_prefs.json`, шлях — `SILPO_PREFS_PATH`) інжектиться
в системний промпт агента і діє в усіх сценаріях:

| Потреба | Як вирішено |
|---|---|
| Відстежувати улюблене, що зникло | `--watch-add "товар"` + сценарій `--check-watchlist` (позначка «ЗНОВУ В ПРОДАЖУ»; можна ганяти кроном з `--telegram`) |
| База частих покупок + де економити | `--savings`: топ-15 з історії замовлень, акції на часте, дешевші аналоги, економія в грн/міс |
| Швидко переглянути новинки | `--novelties`: кураторські добірки й категорії з урахуванням преференцій |
| Ніколи не бачити товари з доставкою НП | `--hide-np` — постійний фільтр у промпті |
| Бути першим у черзі на доставку | `--slots` + правило в промпті: завжди перевіряти і пропонувати найранішній слот |
| Максимум балабонусів vs знижки | `--bonus-plan`: порівняння в грн «отримати бонуси» vs «списати бонуси» vs знижки |
| Бренди, які ніколи не купую | `--ban-brand "Бренд"` — стоп-лист у промпті, з пропозицією альтернатив |

Сценарії зі списку — readonly за задумом (промпт явно каже «нічого не
додавай у кошик»), плюс діють загальні guardrails.

Регулярна перевірка вотчліста через наявний APScheduler (Procfile) або cron:
`python -m app.silpo_agent.cli --check-watchlist --read-only --telegram`.

## Запуск

```bash
pip install -r requirements.txt

export ANTHROPIC_API_KEY=...       # ключ Anthropic (лише на сервері)
export SILPO_MCP_TOKEN=...         # токен MCP «Сільпо» (видається після реєстрації)

# 1. Перевірка підключення: перелік інструментів
python -m app.silpo_agent.cli --list-tools

# 2. Прямий виклик інструмента без LLM (назву взяти з tools/list)
python -m app.silpo_agent.cli --call <toolName> --args '{"query": "борщ"}'

# 3. Повне демо (write-дії питатимуть підтвердження; --yes для автопідтвердження)
python -m app.silpo_agent.cli "Збери кошик для борщу на 6 осіб до 800 грн" --audit audit.jsonl

# 3а. Безпечний режим без змін стану
python -m app.silpo_agent.cli --read-only "Що з акцій підійде для борщу?"

# Тести (без мережі, на моках)
python -m pytest tests/test_silpo_agent.py -v
```

> Локально MCP-сервер можна під'єднати й до Claude Code:
> `claude mcp add --transport http silpo https://mcp.silpo.ua/mcp`
